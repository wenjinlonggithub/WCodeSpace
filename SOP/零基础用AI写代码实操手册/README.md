# AI编写代码 标准SOP大纲（可直接做成PDF目录，闲鱼/拼多多售卖版）
## 前言
1. 本SOP核心定位：**零基础也能用AI产出可直接运行代码**
2. 核心逻辑：不卖编程技能，只给「套模板→输需求→出可用代码」标准化流程
3. 适用价值：自用提效、副业接单、脚本开发、自动化办公全覆盖

## 一、适用人群
1. 零基础小白，不会编程但需要写代码
2. 在职程序员，想用AI提速开发、减少加班
3. 副业想接单，靠AI写脚本/小程序赚外快
4. 办公职场人，需要自动化处理Excel、表格、批量操作

## 二、前置准备：必备工具清单（零门槛）
1. AI模型选择（适配写代码首选推荐）
2. 代码运行/编辑工具安装与极简使用
3. 浏览器、插件辅助配置
4. 文件夹规范：代码文件统一存放命名规则

## 三、AI写代码通用标准5步SOP（核心主干）
1. 需求拆解：把模糊想法拆成**功能、场景、限制条件**
2. 套用标准提示词模板，输入完整需求
3. AI一次性生成完整代码
4. 本地复制、运行、初步自测
5. 微调优化：一句指令让AI改bug、简化、加注释

## 四、多场景专用提示词库（直接复制即用）
1. Python自动化脚本专用提示词
2. Excel/表格批量处理脚本提示词
3. 数据分析、统计可视化代码提示词
4. 简单网站/页面开发提示词
5. 小程序、工具类简易代码提示词
6. 爬虫、批量采集合规版提示词
7. 职场办公重复工作自动化提示词

## 五、代码调试&纠错SOP
1. AI代码常见报错类型快速识别
2. 固定句式指令，让AI自动排查bug
3. 代码精简、加注释、改成易懂版本话术
4. 兼容适配、低配置电脑可用优化方法

## 六、副业接单专属：代码交付标准化SOP
1. 客户需求问询固定话术
2. 报价参考区间
3. 代码打包规范：源码+使用教程+运行说明
4. 交付格式、售后边界设定
5. 避免反复改稿的沟通SOP

## 七、常见问题FAQ（新手必看）
1. AI生成代码不能运行怎么办
2. 太复杂看不懂怎么简化
3. 如何让AI写出更稳定、少报错的代码
4. 不用懂语法，怎么判断代码靠不靠谱

## 八、新手避坑红线
1. 禁止做的高风险代码场景
2. 避免过度依赖AI完全不动脑
3. 接单避坑：客户无理需求怎么婉拒

## 九、进阶升级（引流知识星球专用）
1. 高阶长文本代码提示词进阶写法
2. AI代码副业完整接单渠道SOP
