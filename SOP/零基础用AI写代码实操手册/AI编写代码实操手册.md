## 前言：这本手册能帮你做什么

很多人买了 AI 工具，用了一段时间之后发现——

让 AI 写代码，写出来的东西要么跑不起来，要么跑起来了但不是自己想要的，要么改了三四轮还是一团乱麻，最后放弃了。

问题不在 AI 不够聪明，问题在于**你不知道怎么跟 AI 说话**。

这本手册就是解决这个问题的。

我不会教你编程语法，不会让你背什么 Python 基础，也不会讲什么计算机原理。这本手册只做一件事：

**给你一套标准化的流程 + 可以直接复制的提示词模板，让你照着做就能让 AI 产出可以直接运行的代码。**

你需要的不是学会编程，你需要的是学会**指挥 AI 编程**。

这两件事差别很大。

学编程要几个月甚至几年，学会指挥 AI 编程，认真看完这本手册，今天就能上手。

---

### 这本手册的核心逻辑

```
模糊想法 → 拆解需求 → 套提示词模板 → AI 生成代码 → 复制运行 → 微调优化
```

整个流程你不需要懂代码，只需要懂**你自己想要什么**，然后用手册里的模板告诉 AI。

---

### 手册适合什么场景用

- 自动化处理 Excel 表格、批量重命名文件、定时发邮件
- 写一个简单的数据统计脚本、生成图表

<a name="第三章"></a>
## 第三章：AI 写代码通用标准 5 步 SOP（核心主干）

这一章是整本手册最重要的部分。

很多人用 AI 写代码失败，根本原因是**提需求的方式不对**。你跟 AI 说「帮我写个 Excel 处理脚本」，AI 不知道你要处理什么、怎么处理、输出什么格式，只能瞎猜，写出来的东西自然不是你想要的。

标准 5 步 SOP 就是解决这个问题的。

---

### 第一步：需求拆解——把模糊想法变成清晰指令

在跟 AI 说话之前，先自己想清楚三件事：

**① 功能是什么？**（你要 AI 做什么）

不好的描述：「帮我处理一下 Excel」
好的描述：「读取 Excel 文件，把 A 列中重复的行删掉，按 B 列的数字从大到小排序，保存成新文件」

**② 场景是什么？**（在什么环境下运行）

- 操作系统：Windows 还是 Mac？
- 文件格式：Excel 是 .xlsx 还是 .csv？
- 数据量：几行？几万行？
- 运行方式：双击运行？还是命令行？

**③ 限制条件是什么？**（有什么特殊要求）

- 不能用某些库（比如公司电脑装不了）
- 输出格式有要求（比如必须保留原来的格式）
- 性能要求（比如要在 10 秒内处理完）

---

**需求拆解练习模板**

拿到一个需求，先填这张表：

```
【功能描述】：我要做什么
（例：批量把文件夹里所有 .txt 文件合并成一个文件）

【输入是什么】：数据从哪里来，是什么格式
（例：D盘/文本文件夹/ 下的所有 .txt 文件）

【输出是什么】：结果长什么样，保存在哪里
（例：合并后保存为 D盘/合并结果.txt，每个文件内容之间用分隔线隔开）

【运行环境】：什么系统，用什么语言
（例：Windows 10，用 Python）

【特殊要求】：有没有额外限制
（例：文件按文件名字母顺序合并，不是按修改时间）
```

---

### 第二步：套用标准提示词模板

需求想清楚之后，套这个万能模板：

```
【通用代码生成提示词模板】

你是一个专业的 [Python/JavaScript/其他语言] 开发者。

请帮我写一段代码，实现以下功能：

【功能描述】
[填写你要做什么]

【输入说明】
[填写输入数据的格式、来源、示例]

【输出说明】
[填写期望的输出结果、格式、保存位置]

【运行环境】
操作系统：[Windows/Mac/Linux]
语言版本：[Python 3.11 / Node.js 18 等]

【特殊要求】
[填写任何额外限制，没有就写"无"]

要求：
1. 代码要完整，可以直接复制运行，不要省略任何部分
2. 关键步骤加上中文注释，方便我理解
3. 如果需要安装第三方库，在代码开头注明安装命令
4. 代码要有基本的错误处理，遇到问题给出友好提示
```

---

**实际填写示例：**

```
你是一个专业的 Python 开发者。

请帮我写一段代码，实现以下功能：

【功能描述】
读取一个 Excel 文件，找出 "销售额" 列中数值大于 10000 的行，
把这些行单独保存到一个新的 Excel 文件里。

【输入说明】

【输出说明】

【运行环境】
操作系统：Windows 10
语言版本：Python 3.11

【特殊要求】
如果输入文件不存在，给出友好的错误提示，不要直接报错崩溃

要求：
1. 代码要完整，可以直接复制运行，不要省略任何部分
2. 关键步骤加上中文注释，方便我理解
3. 如果需要安装第三方库，在代码开头注明安装命令
4. 代码要有基本的错误处理，遇到问题给出友好提示
```

### 第三步：AI 一次性生成完整代码

把填好的提示词复制到 AI 对话框，发送。

等 AI 回复，你会得到类似这样的代码：

```python
# 安装依赖：pip install openpyxl pandas
import pandas as pd
import os

def filter_high_sales(input_file, output_file, threshold=10000):
    """筛选销售额大于指定阈值的记录"""
    # 检查输入文件是否存在
    if not os.path.exists(input_file):
        print(f"错误：找不到文件 {input_file}，请检查路径是否正确")
        return
    
    # 读取 Excel 文件
    print("正在读取文件...")
    df = pd.read_excel(input_file)
    
    # 筛选销售额大于阈值的行
    filtered_df = df[df['销售额'] > threshold]
    print(f"共找到 {len(filtered_df)} 条销售额大于 {threshold} 的记录")
    
    # 保存到新文件
    filtered_df.to_excel(output_file, index=False)
    print(f"已保存到：{output_file}")

# 运行
filter_high_sales(
    input_file=r"D:/数据/销售数据.xlsx",
    output_file=r"D:/数据/高销售额记录.xlsx"
)
```

### 第四步：本地复制、运行、初步自测

**操作步骤：**

1. 把 AI 给的代码**完整复制**（不要只复制一部分）
2. 打开 VS Code，新建一个 `.py` 文件
3. 粘贴代码，保存
4. 如果代码开头有 `pip install xxx`，先在终端运行这个命令安装依赖
5. 运行代码，看结果

**自测检查清单：**

```
□ 代码有没有报错？
□ 输出结果是不是我想要的？
□ 输出文件有没有生成？
□ 数据有没有丢失或者乱码？
□ 边界情况：如果输入文件是空的，会怎样？
```

---

### 第五步：微调优化——一句指令让 AI 改 bug、简化、加注释

代码跑起来了，但可能还有一些小问题，用这些固定句式让 AI 帮你改：

**改 bug：**

```
上面的代码运行后报了这个错误：
[把错误信息完整粘贴过来]
请帮我修复这个问题，给出完整的修改后代码。
```

**改需求：**

```
代码基本可以用，但我需要调整一下：
[描述你想改的地方]
请在原来代码的基础上修改，给出完整的新版本。
```

**加注释：**

```
请给上面的代码每一个关键步骤加上中文注释，
让完全不懂编程的人也能看懂每一行在做什么。
```

**简化代码：**

```
上面的代码能不能简化一下？
我只需要核心功能，不需要那么多复杂的处理，
尽量让代码短一点、简单一点。
```

## 第四章：多场景专用提示词库（直接复制即用）

### 4.1 Python 自动化脚本专用提示词

**场景：批量重命名文件**

```
你是一个专业的 Python 开发者。

请帮我写一个批量重命名文件的脚本，要求如下：

【功能】
把指定文件夹里所有 [填写文件类型，如 .jpg] 文件按顺序重命名，
格式为：[填写前缀，如 photo]_001.jpg、photo_002.jpg……以此类推

【输入】
文件夹路径：[填写你的文件夹路径，如 D:/图片/]

【要求】
1. 按文件的修改时间排序，最早的排第一
2. 重命名前先预览一下会改成什么名字，让我确认后再执行
3. 原文件名备份到一个 txt 文件里，方便以后还原
4. 代码完整可运行，加中文注释
5. Windows 系统，Python 3.11
```

## 第五章：代码调试 & 纠错 SOP

AI 写的代码不是每次都能一次跑通，遇到报错很正常。这一章教你怎么快速定位问题、让 AI 帮你修复。

---

### 5.1 AI 代码常见报错类型快速识别

拿到报错信息，先看最后几行，那里是最关键的错误描述。

**常见报错类型对照表：**

| 报错关键词 | 含义 | 常见原因 |
|-----------|------|---------|
| `ModuleNotFoundError` | 找不到模块 | 没有安装对应的库 |
| `FileNotFoundError` | 找不到文件 | 文件路径写错了 |
| `PermissionError` | 没有权限 | 文件被其他程序占用，或没有读写权限 |
| `SyntaxError` | 语法错误 | 代码本身有问题（复制不完整） |
| `KeyError` | 找不到键 | Excel 列名写错了，或数据里没有这一列 |
| `ValueError` | 数值错误 | 数据格式不对，比如把文字当数字处理 |
| `UnicodeDecodeError` | 编码错误 | 文件编码不是 UTF-8，中文乱码 |
| `IndexError` | 索引越界 | 数据比预期的少，访问了不存在的位置 |

---

**最常见的两个问题和解决方法：**

**问题一：`ModuleNotFoundError: No module named 'pandas'`**

解决：在终端运行 `pip install pandas`，安装完再运行代码。

如果 pip 安装很慢，换国内镜像：
```
pip install pandas -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**问题二：`FileNotFoundError: [Errno 2] No such file or directory`**

解决：检查文件路径。Windows 路径注意两点：
- 用正斜杠 `/` 或者双反斜杠 `\\`，不要用单反斜杠 `\`
- 路径里有中文或空格，加上 `r` 前缀：`r"D:/我的文件/数据.xlsx"`

### Q1：AI 生成的代码不能运行怎么办？

**先别慌，按这个顺序排查：**

**第一步：看报错信息**

运行代码后，终端会显示红色的报错信息。把最后几行复制下来，这是最关键的部分。

**第二步：对照第五章的报错类型表**

看报错关键词，快速判断是什么问题：
- 有 `ModuleNotFoundError` → 先装库：`pip install 库名`
- 有 `FileNotFoundError` → 检查文件路径是否正确
- 有 `SyntaxError` → 代码复制不完整，重新复制

**第三步：把报错发给 AI**

用第五章的「报错修复请求」模板，把完整报错信息发给 AI，让它帮你修复。

**方法一：让 AI 加注释**

**方法二：让 AI 重新写一个简单版本**

### Q4：不懂语法，怎么判断 AI 写的代码靠不靠谱？

不需要看懂每一行代码，用这几个方法判断：

**方法一：让 AI 自己解释**

```

```

如果 AI 的解释和你的需求对得上，代码大概率是对的。

**方法二：用小数据测试**

先用少量数据（比如 5 行 Excel）测试，确认结果正确后再用全量数据。

**方法三：让 AI 列出可能的风险**

```
这段代码有没有什么潜在的问题或者风险？

```

- 有错误处理的，比没有的更可靠

## 第八章：新手避坑红线

这一章说的是「不能做的事」，比「能做什么」更重要。

---

### 8.1 禁止做的高风险代码场景

以下场景坚决不碰，不管客户出多少钱：

**① 涉及他人隐私数据的爬虫**

不要写爬取用户个人信息（手机号、身份证、地址）的代码，这涉及违法。

**② 绕过验证码、模拟登录的脚本**

很多平台明确禁止自动化登录，轻则封号，重则法律风险。

**③ 批量注册账号、刷量、刷评论**

这类需求本质是作弊，平台会封号，严重的涉及不正当竞争。

**④ 破解、逆向、绕过付费验证**

这是侵权行为，不碰。

**⑤ 涉及金融交易的自动化脚本（没有专业背景的情况下）**

自动化交易涉及资金安全，一个 bug 可能造成重大损失。

---

**遇到这类需求，婉拒话术：**

```
您好，这个需求涉及到 [简单说明原因，如 用户隐私数据/平台规则限制]，
我这边没办法接这类单子，抱歉。

如果您有其他需求，欢迎继续沟通。
```

---

### 8.2 避免过度依赖 AI 完全不动脑

AI 是工具，不是大脑。有几件事你必须自己做：

**① 需求要自己想清楚**

AI 不知道你的业务场景，你必须自己把需求想清楚再告诉它。需求模糊，代码就会跑偏。

**② 结果要自己验证**

AI 写的代码可能有逻辑错误，但不会报错。比如统计数据时用了错误的计算方式，代码跑通了但结果是错的。你必须用已知数据验证结果是否正确。

**③ 不要把 AI 的代码直接用于生产环境**

如果是给公司用的、涉及真实数据的脚本，一定要先在测试数据上跑通，确认无误后再用真实数据。

**④ 重要数据操作前先备份**

任何会修改或删除文件的脚本，运行前先备份原始数据。

---

### 8.3 接单避坑：客户无理需求怎么婉拒

**坑一：需求无限扩展**

客户说「就改一点点」，但「一点点」加起来超过了原来的工作量。

应对：每次改动前确认是否在原需求范围内，超出范围的额外报价。

**坑二：要求「包教会」**

有些客户买了代码还要你手把手教他们编程，这不在服务范围内。

应对：
```
我可以提供代码的使用说明和基本的使用问题解答，
但编程教学不在本次服务范围内。
如果您需要学习编程，可以考虑专门的编程课程。
```

**坑三：要求「永久维护」**

应对：明确说明售后期限（比如 3 天或 7 天），超出期限的维护需要额外付费。

**坑四：先做后付**

新客户不要先做后付，至少收 50% 定金再开始。

**坑五：需求描述极其模糊**

客户说「帮我做个系统」但说不清楚具体要什么，这种单子不接或者先收需求分析费。
